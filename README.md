# TG WS Proxy для iOS

Нативное iOS приложение для запуска Telegram WebSocket прокси.

## Возможности

- 🚀 Запуск и остановка прокси одним нажатием
- 🎨 Modern UI с эффектом liquid glass
- ⚙️ Настройка параметров (хост, порт, secret)
- 📋 Просмотр логов в реальном времени
- 📱 Полная поддержка iOS 14+
- 🔗 Быстрое копирование ссылки подключения

## Требования

- iOS 14.0 или выше
- Xcode 14.0 или выше
- Swift 5.7+

## Установка

1. Клонируйте репозиторий
```bash
git clone https://github.com/Werhes/tg-ws-proxy-ios.git
cd tg-ws-proxy-ios
```

2. Откройте проект в Xcode
```bash
open TGWSProxy.xcodeproj
```

3. Выберите целевое устройство и нажмите Run (⌘R)

## Использование

### Вкладка Proxy
- Просмотр статуса прокси
- Запуск/остановка прокси
- Копирование ссылки подключения
- Быстрый переход в Telegram

### Вкладка Settings
- Настройка хоста
- Настройка порта
- Установка secret key
- Переключение режимов

### Вкладка Logs
- Просмотр логов прокси
- Фильтрация по уровню (Info, Warning, Error)
- Автоматическая прокрутка
- Очистка логов

## Интерфейс

### Liquid Glass Design
Приложение использует современный дизайн с эффектом размытого стекла (glassmorphism):
- Полупрозрачные карточки
- Градиентные переходы
- Мягкие тени
- Плавные анимации

## Структура проекта

```
TGWSProxy/
├── TGWSProxyApp.swift          # Точка входа
├── Views/
│   ├── ContentView.swift       # Главное окно с вкладками
│   ├── ProxyTabView.swift      # Вкладка управления прокси
│   ├── SettingsTabView.swift   # Вкладка настроек
│   ├── LogsTabView.swift       # Вкладка логов
│   └── GlassCard.swift         # Компонент liquid glass карточки
├── Models/
│   └── ProxyManager.swift      # Управление состоянием прокси
└── Info.plist                  # Конфигурация приложения
```
